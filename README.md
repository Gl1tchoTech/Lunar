# 🌙 Lunar

> An elegant yet modern music player.

Lunar is a beautifully crafted music player designed to make listening feel as good as the music itself. Clean typography, fluid motion, and a focus on what's playing — not on the controls.

---

## ✨ Features

- **Immersive playback** — Album art takes center stage with a refined, distraction-free interface.
- **Elegant typography** — Carefully tuned type scales and spacing for a premium reading experience.
- **Fluid motion** — Smooth transitions and tasteful micro-interactions throughout.
- **Smart library** — Organize tracks, albums, artists, and playlists with ease.
- **Now playing** — Glanceable controls with rich metadata and gorgeous artwork.

---

## 🎯 Design Philosophy

Lunar is guided by a few simple principles:

1. **Music first.** The interface recedes so the listening experience can shine.
2. **Restrained beauty.** Elegant, not ornate — every detail is intentional.
3. **Effortless motion.** Animation guides the eye, never distracts from it.
4. **Quiet by default.** No clutter, no noise — just your library and your sound.
